# グリッド模写練習アプリ

iPad Safari / Apple Pencil向けの模写練習ツール。ブラウザ内で動作し、画像をサーバーへ送信しない。

## 使い方

「画像を選ぶ」で参照画像を読み込み、2本指で拡大・回転・移動する。マウスでのドラッグと倍率ボタンも使える。描き始めると参照画像の位置を自動固定する。「位置固定中」を解除すれば、再び調整できる。

ペンは黒・固定線幅。筆圧は使用しない。指では描画せず、Apple Pencilまたはマウスで描画する。消しゴムとUndo/Redoを備える。Ctrl / ⌘ ZでUndo、Ctrl / ⌘ Shift ZでRedo、Ctrl / ⌘ SでPNG保存。

グリッドは4×5または8×10。各マスを半分に分ける補助グリッドは常に主グリッドと一緒に表示する。設定から色と線幅（細め・標準・太め）を変更できる。「グリッド OFF」は主線・補助線の両方を非表示にする。

比較時は薄い参照画像を描線の**下**に表示する。「参照画像の濃さ」で調整する。画像・描画・グリッドは同じ4:5の紙面座標を使い、両ペインを実測して同じ表示寸法に合わせる。縦画面では上下配置になり、描画や保存を妨げる全面警告は出さない。

## 保存と復元

PNGは線画のみ、**576×720px固定**。初期設定は白背景。設定で透明背景を選択できる。参照画像とグリッドは書き出さない。iPadではSafariのダウンロード先からファイルを取り出す。

直近1件の練習をIndexedDBに自動保存する。完了したストロークは直ちに保存要求を送り、設定変更は250msまとめて保存する。下部の「この端末に保存済み」は保存トランザクションの完了を示す。復元は現在の描画・参照画像・変形・設定が対象で、過去のUndo/Redoの分岐履歴は保存しない。

ブラウザデータの削除、容量不足、ストレージの自動消去、保存完了前の強制終了には耐えられない。重要な成果はPNGでも保存する。復元に失敗した場合は保存内容を自動で上書きしない。複数タブの同時編集・同期は非対応（最後に保存された練習が残る）。オフライン起動を保証するPWAではない。

「画像を変更」は描画を保持する。「描画を消去」はUndoできる。「新しい練習」は確認後に画像・描画・設定・履歴を初期化する。

## 実装・対応範囲

論理紙面は640×800。表示用Canvasのみを画面サイズ・DPRに合わせて再生成し、ストロークデータから再描画する。出力サイズや座標は画面回転・設定パネルの開閉・DPRで変化しない。

ビルドターゲットはSafari 16.4以降（iPadOS 16.4以降）、Chrome 111以降、Firefox 114以降。これは互換性の設計ターゲットで、すべての端末を実機検証したという意味ではない。`getCoalescedEvents()`は機能検出し、非対応環境では通常のPointerイベントへ戻す。

画像は40MB以下、デコード後6400万画素以下を受け付け、保存・表示用に最大辺2560pxへ正規化する。非対応形式や壊れた画像はエラー表示し、既存の参照画像を保持する。

## 開発とテスト

Node.js 22.12以降を使用する。

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
```

ブラウザテストはPython 3.12以降とPlaywrightを使用する。

```sh
python -m pip install playwright==1.58.0
python -m playwright install --with-deps chromium webkit
npm run build
npm run test:browser
```

純粋関数のテストに加え、実際のReactアプリをブラウザで操作し、連続Undo/Redo、繰り返し消去、リサイズ、別ポインターの終了、最終座標、グリッド整合、PNGの寸法・アルファ、復元とフォーカス保持を検証する。iPad実機のApple Pencil遅延・パームリジェクション・OSジェスチャーの確認は別途必要。

CIはpush / PRでlint・単体テスト・ビルド・Chromium / WebKitのブラウザテストを実行し、mainの検証成功後にGitHub Pagesへデプロイする。結果とスクリーンショットはActionsの`browser-tests`アーティファクトに残る。
